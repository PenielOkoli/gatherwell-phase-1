# Module 1 product brief — Gatherwell

This is a new product concept created for this submission. It does not reuse the earlier CoinPilot AI concept, branding, application, or repository. No separate Module 1 brief was supplied for this new idea, so this brief makes the assumptions explicit.

## Problem and audience

Team leads and community facilitators often have a goal for a gathering but no clear plan for using the time. An unstructured session can leave quieter people out and end without a decision. Gatherwell helps a facilitator prepare a practical workshop agenda before people arrive.

## Product promise

Turn a goal, duration, group size, and gathering format into a five-part agenda with clear timeboxes, inclusive prompts, and a concrete closing commitment.

## Core journey

1. Start with a team alignment, idea exploration, or retrospective template.
2. Edit the title, desired outcome, time available, number of participants, and format.
3. Build and review a timed agenda. Expand each activity to see instructions and its intended outcome.
4. Save locally or download a Markdown agenda for use outside the app.
5. Ask the facilitator guide a question or read the original playbook notes.

## Phase 1 scope

- Functional, deterministic agenda builder for 30, 60, and 90 minutes; groups of 2–30; in-person and remote formats.
- Public demo assistant with curated responses. Every response is labeled as demo.
- Real AI SDK provider adapter behind an authenticated server endpoint, ready for later modules.
- Browser-local saved workshops (up to 20), with runtime validation when loaded.
- Server-written, HttpOnly preference cookie to remember the gathering format for 30 days.
- Responsive, keyboard-accessible UI and server-rendered reference pages.

## Deliberate limits and next modules

This foundation does not include accounts, cross-device persistence, calendars, invitations, real-time collaboration, or AI streaming. The app does not pretend that template output was generated by a model. Public paid AI access needs user authentication, a durable rate limiter, quotas, and operational monitoring before release. A database can later replace browser storage without changing the WorkshopPlan contract.

## Acceptance criteria

An agenda contains exactly five positive-duration activities whose minutes sum to the chosen duration. Remote plans refer to a shared digital board. Large groups use smaller breakout groups. A saved plan can be reopened after a refresh on the same browser. A downloaded agenda includes the goal, settings, activity instructions, and outcomes. Malformed server input is rejected even if browser validation is bypassed.
